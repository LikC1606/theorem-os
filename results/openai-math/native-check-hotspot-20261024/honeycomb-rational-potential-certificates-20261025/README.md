# 高度 3、4 的有理势能证书候选

[精确检查脚本](check_certificates.py)从 canonical honeycomb 邻接重建平移归一化的有向入边状态，核对先前枚举表，并逐行验证 `q * sum(successor weights) <= p * current weight`。高度 3 用 `beta=11/6`、16 个状态、权重 6–11；高度 4 用 `beta=1847/1000`、22 个状态、权重 29–64。全部比较使用任意精度整数和有理数。

[完整证书](certificates.json)给出状态、下一步、各行权重与不等式余量。两个 beta 均正，且 `(beta²-2)²<2`、`beta²-2>0`，所以数学上严格小于 `sqrt(2+sqrt(2)) = 2*cos(pi/8)`。这些权重是精确有理线性方程求解后取整获得的候选；交付只依赖可重算的逐行不等式。

预期用法是给非回退有限路径枚举归纳出 `N(n,a,b) <= (w(a,b)/min(w))*beta^n`，再把 canonical BridgePath 注入该枚举，接入已有计数到可和性引理。它可避免高度 3 的五步和高度 4 的十四步展开。

这是有限算术诊断，没有 Lean 验证或原生验收效力。到原始无限路径的形式化连接、归纳与可和性结论仍待完成。一般高度原题仍未解决。本包未修改活动源码、runtime、state、队列、缓存、回执或旧证据。
