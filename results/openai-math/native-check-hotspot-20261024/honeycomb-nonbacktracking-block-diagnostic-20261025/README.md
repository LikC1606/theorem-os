# 有限宽度非回退延续的整数计数诊断

四种固定高度的非回退计数给出可尝试形式化的局部上界。按水平方向平移归一化有向入边；转移时排除立即回到前一个点。完整状态、转移表及每状态计数保存在 [block-counts.json](block-counts.json)，生成脚本见 [count_blocks.py](count_blocks.py)。

| 高度 | 有向边状态数 | 入边之后的步数 | 最多延续数 |
| --- | --- | --- | --- |
| 1 | 4 | 1 | 1 |
| 2 | 10 | 2 | 3 |
| 3 | 16 | 5 | 20 |
| 4 | 22 | 14 | 5376 |

每行的计数都严格小于 `μ^步数`，其中 `μ = 2 cos(π/8) = sqrt(2+sqrt 2)`。脚本用任意精度整数验证平方后的代数比较；没有浮点误差。高度 2 的独立 Lean 工作另外进行，不能由这份 Python 输出推出已通过 Lean。

该诊断没有使用终点限制，也没有排除更早的重复点，因而可用于寻找对自避免路径的上界。要用于原题，仍须在固定 Lean 中证明规范定义与有限状态编码一致、所有真实路径都被覆盖、块计数归纳成立以及权重可和性。上述比较与连接均未由本包进行内核核验。

本包没有新原生 TaskProof、全高度增长界或原题完成结果，也未修改活动求解链。它保存的是具体有限状态路线的计算证据，供后续形式化复用。
