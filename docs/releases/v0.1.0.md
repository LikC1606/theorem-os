# DeepScientist Math v0.1.0

首个研究预览版：可组合的数学研究组件，以及独立的 Lean 证明验收运行时。
开发者可以替换研究方法中的一个组件，并在固定题目与验收条件下运行、恢复和比较实验。

## 发布范围

- M1–M5 分离证明构造、检查反馈、搜索决策、上下文选择与协作复用，组件带独立版本。
- [可运行的 M3 替换示例](../../examples/components/README.md)，保留其余组件和宿主最终验收。
- 单智能体、独立并行、任务协作，以及按需协助的 `primary-led` 策略。
- S1 保存候选、失败、检查回执、会话与累计用量；支持断点恢复和计划修改。
- S3 固定题目与环境，对完整原题独立重检；模型完成消息和局部证明不能代替最终验收。
- IMO2026 与 Lean-Eval 公开题目适配器，以及[固定版本 Q1 复现示例](../../examples/imo2026/README.md)。

## 使用入口

从 [README](../../README.md) 安装、构建并准备题目。
优先用 `--startup-only` 检查环境，再通过 `--resume` 开始模型求解。
扩展研究方法从 [组件合同与替换示例](../../examples/components/README.md) 开始。

## 当前限制

这是源码级研究预览版，组件接口尚未承诺兼容性。
完整运行需要 Linux、可用的 Codex 模型认证、匹配的 Lean/Mathlib，以及隔离依赖环境所需的系统工具。
S2 跨任务学习尚未实现；不提供通用科学研究组件或可视化编排器。
协作策略与性能实验仍在迭代，不承诺相对单智能体的速度或正确率提升。
