# 首页设计参考

2026-10-16 实际浏览了以下四个公开官网的首屏与后续内容。参考的是信息结构和排版方法，页面使用 TheoremOS 自己的源码、记录和图像。

| 官网 | 观察 | 在 TheoremOS 中的应用 |
| --- | --- | --- |
| [Linear](https://linear.app/) | 克制的黑色底、简洁标题，首屏下方直接出现大面积产品界面。后续用不同密度的内容形成节奏。 | 把可交互的预设回放放到首屏标题下方，减少装饰面板与重复口号。 |
| [Cursor](https://cursor.com/) | 标题直接说明产品身份与用途，随后用真实编辑器界面和任务内容展示产品。 | 标题直接露出 TheoremOS 与数学 Agent 研究运行时；演示展示真实预设候选及已归档回执。 |
| [Resend](https://resend.com/) | 类别与受众表达清楚；开发体验部分直接链接代码示例。 | 让本地回放和证明档案成为明确入口；增加来自仓库的 M3 替换代码示例。 |
| [Vercel](https://vercel.com/) | 中性色、简短的产品类别名称和集中且明确的主操作。 | 用石墨黑、银白和少量蓝绿强调状态，简化操作层级。 |

本次没有使用这些网站的客户标志、推荐语、指标或素材。Lean、mathlib、Lean-Eval 与 Bun / TypeScript 一行表示工具生态。

## 产品事实与展示边界

- 首屏四步演示的候选源码读取自 `src/math/localExample.ts`，最终回执读取自 `docs/assets/replay.json`。反馈步骤是对预设示例的解释，不伪装成原始诊断日志。
- 最终回执始终标为“已归档的最终验收”。切换较早步骤不会把成功回执误标为当时的状态。
- 网页不启动 Agent 或 Lean。演示标明预设回放、不调用模型、非实时运行。
- 官方证明成果继续由档案数据生成，保留原项目与模型归属。
- 组件图与研究档案身份图均是结构示意，不表示固定线性流程、实时调度或已测量的性能。

## 验证重点

检查四步演示与组件切换的鼠标、触摸和键盘操作；本地文件与 Pages 子路径的资源加载；320–1920 像素的换行和溢出；减少动效设置；官方证明链接和档案来源的一致性。
