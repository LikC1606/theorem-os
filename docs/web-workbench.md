# 网页研究工作台

`apps/web` 提供独立网页和 HTTP API，通过 Docker 启动一次性的求解 worker，复用现有 `runSolver()`、原题固定机制和最终 Lean 验收。CLI 不依赖此服务。

## 本地启动

需要 Linux、Docker Engine / Compose，以及允许非特权用户创建用户命名空间的宿主机。Mathlib 运行还需要可用的 `/dev/fuse`。每个容器上限为 2 CPU，Mathlib 内存上限 8 GiB、标准库 4 GiB，默认一次运行一个任务。建议为每个并发 Mathlib 运行预留 30 GiB 可用磁盘；冷准备会按依赖体积约三倍检查磁盘余量。

首次构建需联网下载 Bun、Codex CLI、固定 Lean 工具链、Mathlib 源码和预编译依赖，镜像较大，下载可能较慢。构建会复用下载缓存、重试失败下载，并执行完整 Mathlib 构建和 `import Mathlib` / `ring` 探针。

```bash
git clone https://github.com/LikC1606/theorem-os.git
cd theorem-os
docker compose -f apps/web/compose.yml build worker web
docker compose -f apps/web/compose.yml up -d web
docker compose -f apps/web/compose.yml ps
```

浏览器打开 <http://127.0.0.1:8787>，左侧输入研究任务，右侧预览 Lean 原题。点击研究配置选择证明环境、模型并输入自己的 API Key，发送任务开始研究。新建研究默认使用 Mathlib；可切换到 Lean 标准库。配置中显示当前环境的固定 Lean 工具链和 Mathlib revision，模板列表只包含所选环境的示例。切换环境时，已选择的模板会更换为对应示例；自定义源码与任务保留，请自行确认其 import 和 tactic 属于所选环境。

输入区上方会提示当前缺少的提交配置，点击提示可直接前往对应字段。首次进入时需要填写 API Key；所有字段满足本地格式检查后显示“提交配置已填写”，Key 与模型的可用性在实际提交时确认。空白任务、模型或密钥格式错误、超出字节大小和执行预算限制会在字段旁提示，修正后清除；这些本地检查不会创建任务或调用服务商。

网页默认使用宿主机已部署的 Sub2API 网关、`deepseek-flash` 模型和 `max` 推理强度，API Key 填写该网关的访问密钥。OpenAI 保留为可选服务商；切换服务商后，请填写该服务商实际提供的模型，并选择其支持的推理强度。已保存的草稿保留原配置，可在研究配置中手动调整。

默认网关地址为 `http://host.docker.internal:8080/v1`。worker 启动时通过 Docker `host-gateway` 映射访问宿主机，因此网关的 8080 端口需要对 Docker bridge 可达。CLI 使用的 `http://127.0.0.1:8080/v1` 指向同一网关；在 worker 容器里，`127.0.0.1` 指向容器自身。每次 Sub2API 运行都会生成独立的 DeepSeek 模型配置，固定 131,072 Token 上下文并支持 `max` 推理强度。

### 配置研究模块

打开「研究配置 → 模块方案」，或点击草稿模块图中的配置图标，可选择 M3 搜索策略与 M4 上下文范围，并新增自定义策略。每项策略包含名称、所属模块、规则、启用开关及「补充默认建议 / 替换默认建议」。支持 M1 证明构造、M3 搜索决策、M4 上下文选择和 M5 协作与复用；M2 检查及 S3 最终验收保持固定。

「模块方案 → 方案库」可命名保存、更新、另存、载入和删除模块组合，同一浏览器最多保留 12 项，每项名称最多 40 个字符。方案库独立于任务草稿，刷新或新建研究后仍保留；仅保存模块配置，不保存任务、Lean 源码、API Key、模型或执行预算。未完成的模块规则也可保存为方案，载入后仍需通过提交校验。

载入方案只替换当前模块配置，同步草稿自动保存与模块图。载入后可撤销，恢复载入前的模块配置并保留任务、源码及预算等其他编辑；继续编辑模块、替换草稿、重置、刷新或提交研究后清除该撤销记录。删除已保存方案不修改当前配置，支持恢复最近删除的一项；恢复时若已满 12 项或名称冲突，会保留原库并提示原因。更新或删除其他标签页已经修改的方案时，需要重新选择，避免覆盖较新的内容。

方案库使用 `localStorage`，写入通过浏览器 Web Locks 协调多标签页操作，因此需要支持 Web Locks 的浏览器，并以 HTTPS 或 localhost（包括 `127.0.0.1`）访问。缺少支持、存储被禁用或容量不足时会显示失败，损坏的库不会被空库覆盖；研究工作台的其他功能仍可使用。方案保存在当前浏览器，暂不跨设备同步。

新增策略默认停用。点击策略右上角的复制按钮，可保留所属模块、策略方式和规则，创建独立副本；副本自动命名并默认停用，可改名、调整规则后再启用。最多保存 8 项，名称最多 40 个字符，单项规则最多 4,000 UTF-8 字节，规则合计最多 16,000 字节；同一模块最多启用一项替换策略，可同时启用多项补充策略。替换仅影响该模块的可配置建议，原题约束、必需数学上下文、角色协议、Lean 检查与独立验收仍会执行。自定义规则作为研究上下文交给模型，不支持上传可执行插件。M5 规则仅在多 Agent、协同模式且实际进入协作上下文时参与；M3 的任务调度预设也仅在协作任务中发挥调度作用。「精简上下文」移除可选材料，保留必需上下文。

策略可单项或全部展开、收起，收起时保留名称、所属模块、策略方式及启用开关。通过上下箭头调整列表位置；同一模块的规则按列表顺序加入上下文，跨模块排序不改变研究模块的执行结构。排序随方案保存和复用，校验时会自动展开并定位有问题的策略。

删除策略后，可通过模块方案底部的撤销图标恢复最近删除的一项，保留规则、原位置、启用及折叠状态，不覆盖其他策略的新编辑。达到 8 项上限时暂不能恢复。撤销记录仅在当前页面内保留，关闭配置后仍可使用；重置、导入、复用或恢复草稿、刷新及实际提交任务时清除。恢复的策略继续接受替换冲突和规则大小校验。

草稿模块图中，点击自定义策略会展开对应规则并定位到详情；详情中的编辑按钮可直接打开该项配置，关闭后返回对应策略。更换所属模块后会定位到新模块，删除后回到模块节点。M1、M3、M4、M5 详情中的新增按钮会创建归属于当前模块的停用策略；达到 8 项上限后禁用新增。已有运行中的模块方案只供查看，不提供编辑或新增入口。

草稿模块图的策略列表可直接启停规则，开关与研究配置、草稿保存同步。普通启停保留当前查看的模块、焦点和阅读位置；启用缺少规则或存在替换冲突的策略时，打开配置并定位待修正字段。已有运行隐藏开关，提交期间禁用编辑。

手机上从工作区打开研究配置时，关闭配置会返回原工作区；即使未修改配置，也会保留所选模块和策略的阅读状态。提交时回到对话；研究任务校验失败时定位到输入框，配置的关闭事件不会覆盖此次跳转。

模块方案随草稿自动保存，并随任务导入、导出、恢复与「基于此题新建研究」复用。提交时固定本次方案，后续草稿修改不影响已有运行。模块图显示停用、不适用、待应用和已应用次数；次数来自规则实际加入编译上下文的事件，不代表模型调用或证明成功，活动日志轮转后仍可查看累计记录。

更新已有 Docker 部署时，需要重新构建 worker 和 web 镜像，使两端使用同一版模块配置协议。

```bash
# 停止服务；未完成任务会被取消并清理容器
docker compose -f apps/web/compose.yml down
```

默认仅监听本机 8787 端口。请使用 `127.0.0.1` 访问；服务会校验 Host 与公开地址一致。GitHub Pages 只托管静态官网，无法运行此后端。

## 配置兼容 Responses API 的服务

服务商由部署者配置，网页访客从列表选择。地址使用 HTTPS；宿主机网关可使用 `http://host.docker.internal:端口/v1`。地址不能包含凭据、查询串或片段。工作台使用 Codex 的自定义模型服务配置 `wire_api = "responses"`、`env_key` 与 Bearer API Key；Sub2API 需启用 Responses API 兼容端点，仅兼容 Chat Completions 的服务暂不支持。

启动前在 shell 设置以下环境变量，再运行 Compose：

```bash
export THEOREMOS_WEB_PROVIDERS='[{"id":"sub2api","name":"Sub2API · DeepSeek","baseUrl":"http://host.docker.internal:8080/v1"},{"id":"openai","name":"OpenAI","baseUrl":"https://api.openai.com/v1"}]'
docker compose -f apps/web/compose.yml up -d web
```

上例与默认服务商列表一致；网关使用其他端口或 HTTPS 域名时，修改第一个地址。这里仅配置服务地址；用户的 API Key 在网页中逐次输入。

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `THEOREMOS_WEB_PUBLIC_URL` | `http://127.0.0.1:8787` | 浏览器实际访问的 origin，不带子路径 |
| `THEOREMOS_WEB_PROVIDERS` | Sub2API 宿主机 `:8080/v1`、OpenAI `/v1` | 可选服务商 JSON 数组；留空使用默认列表 |
| `THEOREMOS_WEB_CONCURRENCY` | `1` | 同时运行任务数，1–8 |
| `THEOREMOS_WEB_QUEUE_LIMIT` | `8` | 排队与运行中的任务总数，1–32；直接启动时可配置 |
| `THEOREMOS_WEB_WORKER_IMAGE` | `theorem-os-worker:local` | 运行镜像；Compose 使用固定本地标签 |
| `THEOREMOS_WEB_HOST` | `127.0.0.1` | 直接启动时的监听地址；容器内为 `0.0.0.0` |
| `THEOREMOS_WEB_PORT` | `8787` | 直接启动时的端口 |
| `THEOREMOS_WEB_STATIC_ROOT` | `out/web` | 直接启动时的静态文件目录 |

如本机依赖已齐备，也可只用 Docker 跑 worker、用 Bun 启动网页服务：

```bash
bun install --frozen-lockfile
bun run build:web
docker compose -f apps/web/compose.yml build worker
bun run web
```

## 功能范围与数据

- 提供 Mathlib 和 Lean 标准库两种固定环境。新网页任务默认 Mathlib，可使用 `import Mathlib` 和对应版本提供的 tactic；标准库环境不提供 Mathlib。单份源码最多 32 KiB，至少包含一个命名 theorem / lemma；保留原题声明，模型修改证明。暂不支持上传仓库或自定义 Lake 依赖。
- 环境选择随任务保存，运行列表和详情显示实际提交环境；详情显示对应工具链和 Mathlib revision。CLI 的既有行为不受网页默认值影响。
- 概览分别显示排队、环境准备、证明研究、独立验收四个阶段及用时。总用时包含等待与准备，研究用时从真正开始研究时计算，进入独立验收后停止。阶段开始时间独立保存在后端，不受最近 200 条活动日志上限影响；刷新页面后可继续查看。取消或提前结束的任务会标明尚未执行的阶段。
- 桌面使用左右双栏：左侧对话显示已提交任务、真实阶段事件和研究结果，底部保留输入框；右侧默认展示 Lean 源码，并提供模块、概览、报告和活动视图。栏宽可拖动或用分隔条的方向键调整；手机通过“对话 / 工作区”切换。模型连接与执行预算集中在研究配置弹窗，历史记录通过左上角抽屉查看。
- 模块视图展示 M3 搜索、M4 上下文、M1 构造、M2 检查的研究循环，M5 任务协调和独立的 S3 验收。草稿阶段可查看结构，提交后按真实运行事件更新；模块与 Agent 数量相互独立。选择模块可查看最近活动、上下文大小、候选检查结果等已有数据，并进入源码、活动或报告。模块摘要保存在当前运行中，不受最近 200 条活动轮转影响；事件数量是观察次数，不是模型调用、工具调用或 Token 数。并行活动按 Agent 区分，未收到可靠事件的模块保持无记录。条件性与局部检查不会标为最终验收成功，只有任务结束且 `evaluated_passed` 才显示 S3 验收通过。S1 没有独立状态事件，S2 尚未实现，本版不推断这两项的运行状态。
- 模块顶部按事件序号展示最近活动，可定位到对应模块。运行中可开启实时跟随，按新事件更新所选模块，轮询不移动焦点或主动滚动；手选模块或使用定位按钮会暂停跟随，切换任务与任务结束会重置。断线时保留最近状态，恢复后按最新记录继续跟随。详情中的“未结束的 Agent 记录”来自已有开始 / 结束事件，不代表实时请求占用；进入独立验收或运行结束后不再将研究 Agent 记录显示为进行中。
- 模块图通过连续连线和独立的循环区域展示结构；选择模块时显示深色卡片、“查看中”标记及关联路径，运行状态仍由真实事件决定。连线表示模块关系，不表示实际执行顺序。窄屏将配置放在标题下方，并保留完整模块名称、状态和键盘焦点。
- 顶部运行状态栏列出当前会话中排队和执行中的任务，切换草稿、历史筛选或手机视图后仍可直接打开。后台任务在页面轮询观察到结束时保留一条提醒，打开后进入报告，也可忽略提醒；这不会删除历史记录。正在查看的任务结束时不另发提醒，首次加载已有的已结束记录也不重复提醒；提醒不跨页面刷新保存。对话标题旁的返回按钮可回到未提交草稿，保留源码、任务、配置、Key 与草稿恢复备份。切换和忽略提醒均不创建或取消运行。
- 欢迎区标明当前选中的示例题目。设置窗口关闭后返回实际打开它的控件；从设置展开源码编辑器时保留底层设置，关闭编辑器后返回原按钮。导入任务后直接定位 API Key，后续的关闭事件不会覆盖新焦点。
- 尚无运行时，右侧同步展示当前草稿的环境、模型、预算、Agent 数量，源码默认预览前 160 行；打开查找或行号定位后会展开允许大小内的完整源码。预览明确标记未提交，不包含 API Key，也不会创建任务。输入框支持附加 Lean 文件和展开源码编辑器。Enter 提交，Shift+Enter 换行，输入法组合期间不提交。
- 草稿、原始题目和候选源码区分显示 Lean 关键字、tactic、注释、字符串与占位证明。点击“查找源码”可按文本查找，切换大小写并显示匹配数量、行列位置；Enter / Shift+Enter 跳转下一个 / 上一个匹配，Esc 返回源码。源码区获得焦点时也可使用 Ctrl / ⌘ F。最多显示 1,000 个匹配，查找文本最多 256 个字符；超出匹配上限时显示 `+`。查找仅在浏览器进行，不写入草稿或发送请求。实时更新会重算匹配数量并保留焦点和滚动位置。未提供原生文本高亮的浏览器仍支持普通源码、查找计数与定位；差异视图使用已有的更改导航。
- 源码工具栏提供行号定位，在源码区也可使用 Ctrl / ⌘ G。输入当前显示文件中的整数行号后，Enter 定位并返回源码焦点；支持首尾与空白行，长行定位时返回行首，超出范围会显示校验提示。定位仅在浏览器进行，不修改草稿、原始题目、候选证明或验收结论。超限草稿仅允许定位当前展示的前 160 行，实时更新保留正在输入的行号与阅读位置；换运行后重置定位输入。
- 运行中每 1.5 秒采样隔离求解目录中的 `Submission.lean`，变更后通过现有轮询刷新右侧候选源码，保留滚动位置。快照最多 128 KiB，显示采样时间和 Agent，始终标记尚未验收；最终结果中的证明优先于运行快照。源码支持行号、原题切换、差异对比、复制与下载；只有完整原题通过独立验收才显示“验收证明”。
- 草稿编辑、候选源码刷新和对话追加采用局部更新，保留未变化的节点、焦点与选区；分栏拖动按动画帧合并更新。新进展在对话底部自动跟随，阅读历史时保留位置；手机切换视图期间也保留跟随状态，主动跳到最新进展时遵循减少动态效果设置。
- 新会话、主动切换视图和弹窗使用短过渡；跟随最新进展时，仅最后三条新增事件入场。阅读历史、源码候选更新和无变化轮询不会重复播放；页面隐藏、切换手机面板或启用减少动态效果时会清理动效，立即恢复完整内容。
- 详情右上角或研究反馈下方可基于此题新建研究，重新载入该次任务固定的原始源码、研究任务、证明环境、模型和执行预算，API Key 需重新输入。每次发送创建独立任务，目前不提供同一运行内的多轮追问或修改指令。
- 有候选源码的运行支持逐行差异对比，展示原题 / 候选行号与新增、删除统计，默认折叠未改动内容并保留三行上下文，可展开和跳转更改位置。换行格式、末尾缺失换行分别标明；复制与下载仍保留完整候选原文。对比不改变验收结论。浏览器内使用 `diff` 库，在 80 ms / 2,000 编辑步骤预算内生成对比，最多展示 2,000 行；超限会提示，完整源码仍可查看和下载。
- 可从本机导入 UTF-8 `.lean` 文件，导入时只在浏览器读取，点击提交后才发送源码；错误文件和迟到的文件读取不会覆盖新草稿。支持展开源码编辑器、行数与字节计数，应用修改前检查大小和空白输入。存在未应用修改时，取消、关闭或 Esc 会先确认是否放弃；继续编辑保留文本、选区、滚动位置和撤销记录。未修改或撤销回打开时的原文则直接关闭。编辑器暂存内容不自动保存，应用后才写入草稿。
- 展开的源码编辑器提供选中行缩进与反缩进按钮，支持 Ctrl / ⌘ `]` 和 Ctrl / ⌘ `[`。每级缩进添加两个空格；反缩进移除行首最多两个空格或一个 Tab。未选择文本时处理光标所在行，选区结束于下一行行首时不改动下一行；保留选区方向与滚动位置。光标状态显示逻辑行号与 Unicode 字符列号。工具使用浏览器原生编辑事务，保留撤销与重做；Tab / Shift+Tab 仍用于焦点导航。无法执行原生编辑时保留文本并提示，可继续直接编辑。所有操作仅修改弹窗内暂存文本，应用时沿用大小、空白、版本校验与草稿恢复备份。
- 展开编辑器内可用 Ctrl / ⌘ F 查找当前编辑内容，支持字面匹配、大小写切换、Enter / Shift+Enter 循环定位；搜索框持有焦点时仍高亮当前匹配。最多计入 1,000 个匹配，查找文本最多 256 个字符。Ctrl / ⌘ G 可跳到逻辑行行首，支持空白行与末尾空行，并按实际自动折行位置滚动。编辑、撤销或重做后更新匹配和行数，不移动编辑中的光标或改写内容。Esc 先关闭查找或行号工具并返回编辑，再次 Esc 沿用未应用修改确认。查找状态仅在本次打开编辑器期间保留；定位不会应用修改、覆盖草稿或创建运行。
- 查找栏可展开替换，Ctrl / ⌘ H 直接打开并聚焦替换框。支持替换当前匹配或全部替换，沿用大小写设置；查找与替换均按字面文本处理，`$&`、`$1` 和反斜杠没有特殊含义，替换内容留空则删除匹配。单处替换前必须准确选中当前匹配，选区不符时只定位；替换后选中下一处并保留替换框焦点。全部替换覆盖完整源码，不受 1,000 条匹配显示上限影响，整次操作可用一次原生撤销恢复。替换文本最多 256 个字符，扩写超过源码大小限制时保留原文并提示；已有超限草稿仍可缩短，应用时继续校验。替换只修改编辑器暂存内容，应用后才更新草稿与恢复备份；重新打开编辑器时清空查找替换状态。
- 有未应用修改时，点击“查看改动”可在同一编辑器中逐行核对新增、删除与编辑前后的行号；默认折叠未改动行，支持上一处 / 下一处更改。“编辑此处”显示当前更改在新源码中的行号，点击后直接回到首条新增行行首；纯删除则定位到当前源码的删除边界。该操作只移动光标，不选中或改写文本；重新查看时仍保留对比位置。对比以本次打开时的源码为基准，不受底层草稿后续变化影响；应用时仍校验草稿版本。返回编辑保留同一个输入框、选区、滚动与原生撤销记录；编辑内容未变时也保留对比的折叠状态和阅读位置。Esc 先返回编辑，Ctrl / ⌘ F / G / H 和撤销重做也先回到编辑内容。差异计算沿用上述预算，超限明确提示，完整暂存文本保留；导航和编辑入口仅覆盖已展示的更改。查看改动不写入草稿、恢复备份或运行，也不改变 Lean 验收结论。
- 草稿预览查找或跳行成功后可点击“编辑此处”，在展开编辑器中直接选中当前匹配或定位到目标行行首；预览标题旁的编辑按钮也继承此位置。关闭预览查找后保留最后一次成功定位，进入编辑时保持源码焦点，并按实际折行滚动。应用修改使原入口隐藏时，焦点返回预览标题旁的编辑按钮。无结果、清空查询或源码变化后旧位置失效，模型、任务和预算等配置变化不清除位置；行号必须确认跳转后才生效。超限草稿只可继承已展示前 160 行内的位置。历史运行和候选源码保持只读，不能把其查找位置带入独立草稿。
- 源码、研究任务和模型 / 执行配置自动保存在当前标签页的 `sessionStorage`，刷新后恢复，API Key 不写入草稿。重置配置会清除已保存的草稿；不支持存储或内容超限时显示未保存状态，不影响编辑和提交。可导出任务草稿 JSON，也可导入草稿或已下载的运行档案，文件上限 16 MiB；先预览，确认后载入原始题目并清空 API Key，不创建任务或恢复旧验收结论。源码和研究任务仍受各自大小限制。文件读取期间的新编辑不会被迟到内容覆盖。
- 切换示例、重置配置、新研究、复用历史任务、确认导入任务或 Lean 文件、应用源码编辑时，保留替换前的一份完整草稿。输入区和研究配置中可恢复，恢复后需重新填写 API Key；也可丢弃备份。普通输入、取消导入和未改动的编辑不覆盖备份。备份独立于自动保存，正常情况下在当前标签页刷新后仍可恢复；存储不可用或旧草稿超限时仅保留在页面内，并标明“仅本次页面有效”。恢复或实际发送任务时清除备份，恢复不会取消已发送的任务或恢复旧验收结论。
- 历史记录可组合关键词和状态筛选，关键词匹配题目、研究任务、模型、运行 ID、源码和证明环境；只有完成独立验收的记录会进入“验收通过”。状态刷新复用已有记录，保留焦点与未变化文字的选区；新增或移除上方记录时保留正在阅读的行，关闭抽屉再打开也可继续阅读。聚焦记录退出筛选时，焦点转到邻近记录，列表为空则返回搜索框，不自动切换当前详情。主动改变搜索或状态筛选时回到列表顶部；筛选不会清掉当前查看的详情，新任务提交成功后会清除筛选并选中新运行。
- 活动页支持本地关键词与事件类型组合筛选，关键词按文本匹配内容和事件名，不区分大小写。最新记录在前，默认跟随顶部；向下阅读会自动暂停，新增匹配以数量提示，可点击“返回最新”继续跟随。刷新复用已有记录并保持阅读行、选区和筛选框焦点；同一运行切换标签或手机面板后可继续阅读，换运行时重置筛选。仅保留最近 200 条活动，早期记录移出时明确提示，当前选中的事件类型即使没有剩余记录也会保留。可在运行中下载当前筛选结果的活动 JSON，包含运行 ID、筛选条件与保留范围；下载在浏览器生成，不包含 API Key，也不代表完整运行档案。
- 报告页默认展示验收摘要，分别列出候选检查与独立验收、定理级诊断、已有的研究轮次 / 耗时 / Token 统计和验收凭据。单条诊断超过 4000 字符时显示截断提示，可直接打开原始报告；原始 JSON 保留报告中收到的字段，可查看、复制和下载，不代表执行器未提供的日志也已保存。诊断按完整文本去重，相同开头、不同结尾的记录分别保留。缺失的统计不会被补成零，候选检查、单个定理或验收阶段的通过记录不会替代最终结论；最终成功同时要求任务结束和 `evaluated_passed`。
- 已完成、已取消或发生错误的历史记录可在确认后单条删除，删除前可下载包含原始题目与诊断的运行档案，即使任务尚未生成结果。排队或运行中的任务不能删除；删除不会自动取消任务。删除后释放会话的历史容量，不影响其他任务。删除请求的响应丢失时只刷新历史核对，不自动重发。
- 网络中断或请求超过 15 秒时显示连接状态并禁用提交，已有表单仍可编辑；网络恢复、返回页面或手动重连时自动刷新会话和历史。创建任务与取消请求均不自动重发；提交响应丢失时提示结果未确认，并通过历史列表核对，避免重复创建任务。恢复连接不重置未提交的源码、任务或模型配置。
- 取消请求等待期间，对话停止按钮、详情操作和运行状态栏同步显示正在取消，重复操作不会再次发送请求。若轮询已确认该任务取消或结束，迟到的取消响应错误不会再将结果标为未知，也不会因此断线重连；无法确认时仍保留核对提示，不自动重发取消请求。
- 可配置 1–4 个 Agent、任务协作 / 独立并行、1–20 轮和 30–900 秒解题预算。Mathlib 冷准备最长 600 秒，标准库准备和最终验收各有独立时限，均不计入解题预算；轮次和时间不等于 API 费用上限，服务商按自己的计费规则收费。
- 模型结束和网页显示“运行结束”都不代表证明成立。只有 `evaluated_passed` 才显示“验收通过”；这是本地独立 Lean 验收，不是 Lean-Eval 官方成绩。
- 浏览器不把 Key 写入 localStorage / sessionStorage；提交成功后清空输入框。Key 经同源后端内存、Docker stdin 与 Codex 子进程环境传递，不写入 Docker 参数、容器环境配置、Codex 配置文件、任务档案或服务日志。每个任务使用新的 Codex profile，不读取部署者的认证文件；工具 shell 环境排除该 Key。
- 运行记录、源码、进度与结果仅保存在服务内存。每个会话最多保留 20 条记录，可删除已结束的记录以释放容量。有效 API 请求会延长同一会话 Cookie，连续空闲一小时到期；服务重启后清空。需要保留的证明和 JSON 请及时下载。第一版没有账号、跨设备历史或运行恢复。

Mathlib 模板包含以下形式的原题，任务要求模型构造证明，`ring` 可用于完成这个目标：

```lean
import Mathlib

theorem square_expansion (x y : ℝ) :
    (x + y) ^ 2 = x ^ 2 + 2 * x * y + y ^ 2 := by
  sorry
```

Lean 标准库模板保留自然数加法和命题逻辑示例。网页默认 Mathlib 与历史未指定环境的 API 请求有所区别：API 提交 `environment: "mathlib"` 或 `environment: "standard"` 明确选择环境；旧请求省略该字段时仍按标准库处理。

## 部署到服务器

在 Linux 服务器按上述命令构建、运行，再用 Nginx / Caddy 将 HTTPS 域名反向代理至 `127.0.0.1:8787`。设置 `THEOREMOS_WEB_PUBLIC_URL=https://research.example.com`，保留原始 Host 请求头。服务设置 Secure / HttpOnly / SameSite Cookie，并检查请求来源与 CSRF token。不要在反向代理中记录请求体；其中包含访客 Key。

Web 容器是 Docker supervisor，挂载 Docker socket，有权限创建和删除运行容器；请将它部署在用于此产品的受控宿主机上。Worker 不挂载该 socket 或宿主目录，以 UID 10001 和只读根文件系统运行。每次 Mathlib 运行只映射 `/dev/fuse:rw`，并创建一个挂载到 `/var/tmp` 的匿名 local 磁盘卷供准备验证环境；正常结束、取消和失败清理均使用 `docker rm --volumes`。标准库 worker 不映射设备，也不创建磁盘卷。

为嵌套的非特权 Bubblewrap 验证器，worker 放开容器 seccomp / AppArmor profile，并使用 `systempaths=unconfined` 允许在独立 PID 命名空间内挂载新的 procfs。Mathlib 入口的外层 Bubblewrap 在新 user namespace 内仅授予 `SYS_ADMIN` 和 `SETFCAP`，用于构造冻结的依赖环境；Docker 容器仍保留 `--cap-drop=ALL`、`no-new-privileges` 和资源限制，不共享宿主机 PID 命名空间。`/tmp` 的 tmpfs 显式启用 `exec`，供验证器运行临时 Lean 启动脚本，并保留 `nosuid,nodev`。宿主机需要支持这一隔离方式；不支持时应修正宿主机配置，不能跳过 Lean 验证隔离。

没有登录系统，已能访问网站的访客均可提交任务。会话、队列、并发和输入有上限；需要限制公开访问时，可在反向代理配置访问控制。API 限流使用 TCP 对端 IP，每分钟 600 次；经单台反向代理转发的访客共享该限额。

如果首页提示“运行镜像尚未就绪”，确认 worker 镜像已构建，Web 服务能访问 Docker daemon，且镜像标签一致。如果镜像就绪但 Lean 验收无法执行，先运行上述离线 Docker 验证，检查用户命名空间和 Bubblewrap 的宿主机支持。
